# Abass Ibrahim portfolio

An editable Next.js 14 / React 18 application adapted from Rishi Lahoti's MIT-licensed portfolio. See the parent `README.md` and `WINDOWS.md` for the full lab and transfer instructions.

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3000
```

Edit `src/app/data.js` for identity, contact information, projects, and practice areas. Edit `src/app/globals.css` for theme tokens. Components use the reference's SCSS module architecture, GSAP, Framer Motion, and Lenis.

```sh
npm run lint
npm run build
npm run start -- --hostname 127.0.0.1 --port 3000
```

Stop the development server before building. Keep `LICENSE`, `THIRD_PARTY_NOTICES.md`, and `licenses/`. Review `CONTENT_REVIEW.md` before publication. Nothing has been deployed.
